Elementy blokowe

    <a> - hiperlącze do innej strony
    <abbr> - skrót z objaśnieniem w atrybucie title
    <b> - pogrubiony tekst bez szczególnego znaczenia
    <bdi> - izoluje tekst o innym kierunku pisania
    <bdo> - zmienia kierunek pisania tekstu
    <cite> - tytuł dzieła lub źródła
    <code> - fragment kodu
    <data> - wartość zrozumiała dla maszyny
    <del> - usunięty tekst (przekreślony)
    <dfn> - definiowany termin
    <em> - wyróżnienie tekstu (kursywa)
    <i> - kursywa, np. obce słowo
    <ins> - dodany tekst (podkreślony)
    <kbd> - klawisze klawiatury
    <mark> - tekst zaznaczony jak markerem
    <q> - krótki cytat w cudzysłowie
    <s> - przekreślony, nieaktualny tekst
    <samp> - wynik działania programu
    <span> - neutralny kontener do stylowania
    <strong> - ważny tekst (pogrubiony)
    <sub> - indeks dolny
    <time> - data i godzina
    <u> - podkreślony tekst
    <var> - zmienna
    <br> - złamanie linii
    <button> - przycisk
    <img> - obraz
    <input> - pole formularza
    <label> - etykieta pola formularza
    <link> - łączy stronę z zewnętrznym zasobem, np. CSS
    <map> - mapa klikalnych obszarów obrazu
    <meta> - metadane strony
    <output> - wynik obliczenia
    <script> - skrypt JavaScript
    <select> - lista rozwijana
    <small> - mały tekst
    <sup> - indeks górny
    <textarea> - wieloliniowe pole tekstowe
    <progress> - pasek postępu
    <meter> - miernik wartości w zakresie
    <nav> - nawigacja
    <main> - główna treść strony
    <section> - sekcja tematyczna
    <article> - samodzielny artykuł
    <aside> - treść poboczna
    <footer> - stopka
    <address> - dane kontaktowe
    <h1>~<h6> - nagłówki od najważniejszego do najmniejszego
    <hgroup> - nagłówek z podtytułem
    <search> - blok wyszukiwania
    <li> - element listy
    <p> - akapit
    <div> - neutralny blok
    <blockquote> - długi cytat
    <pre> - tekst preformatowany
    <hr> - linia pozioma
    <figure> - ilustracja z podpisem
    <figcaption> - podpis ilustracji
    <ol> - lista numerowana
    <ul> - lista punktowana
    <dl> - lista opisów
    <dt> - termin na liście opisów
    <dd> - opis terminu
    <table> - tabela
    <caption> - tytuł tabeli
    <thead> - nagłówek tabeli
    <tbody> - treść tabeli
    <tfoot> - stopka tabeli
    <tr> - wiersz tabeli
    <colgroup> - grupa kolumn
    <form> - formularz
    <fieldset> - grupa pól formularza
    <details> - rozwijany blok ze szczegółami
    <summary> - tytuł bloku details
    <dialog> - okno dialogowe
    <menu> - lista poleceń
